⚡ slopbgp: gleam on the wire NEW!

our own BGP-4 & MP-BGP routing daemon written in pure Gleam on the Erlang/OTP BEAM for DN42. actor-per-peer supervision isolates misbehaving sessions so bad packets never tear down your routing table.

Global Network Model compiler, GitOps fleet deployment planner & drift detection, multi-router topology simulator with What-If disaster blast-radius analysis, RFC 7938 ECMP & UCMP weighted multi-path, RFC 8205 BGPsec cryptographic signatures, SlopFilter trace & static optimizer engine with RFC 7938 / RFC 7454 route hygiene, RFC 9319 ASPA, RFC 8538 LLGR, RFC 9234 OTC route leak mitigation, RFC 7752 BGP-LS Link-State, RFC 4364 L3VPN Multi-VRF, RFC 8669 Segment Routing (SR-MPLS & SRv6), RFC 5549 BGP Unnumbered, RFC 8210 RTR, RFC 5880 BFD, RFC 7999 RTBH, RFC 7432 EVPN VXLAN, carrier Looking Glass, and dark-mode web dashboard (51 test suites).

📣 trough: federated slop

trough is the open-source fediverse server software we build here, and fedi.freifick.net runs it. inspired by GoToSocial: one Go binary, a SQLite database, and a small appetite.

it speaks ActivityPub to Mastodon, GoToSocial, Misskey and friends. its own web interface works without JavaScript: timelines, follows, replies, likes, boosts, notifications, and image uploads with alt text.

also in the trough: content warnings, post visibility controls, account and domain blocks, and a caching proxy for remote media. use the built-in web UI; Mastodon-compatible clients are supported.

follow @slop@fedi.freifick.net from your fediverse account.

registrations are closed. the slop is public.

🏮 lantern: haskell on the wire NEW!

our own experimental webserver written in Haskell with Caddy-style configuration. built with clean-room protocol libraries from the ground up: strict HTTP/1.1 wire parser (lantern-http), independent TLS 1.3 implementation (lantern-tls), automated ACME certificates, and precompressed Brotli/gzip serving.

one-command static file serving or app reverse-proxying, path prefix stripping, clean TLS closure, RFC 8446 key schedules, and 100% test-verified OpenSSL interop in hermetic Nix builds.
